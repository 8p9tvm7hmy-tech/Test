# داشبورد تحلیل بورس تهران

داشبورد گرافیکی که **همه نمادهای بورس و فرابورس** را از TSETMC می‌گیرد و دو نوع تحلیل انجام می‌دهد:

| بخش | کاربرد | روش |
|---|---|---|
| ⚡ نوسان‌گیری | معاملات کوتاه‌مدت | تحلیل تکنیکال (EMA، RSI، MACD، بولینگر، ATR، حجم، شکست سقف) + جریان پول حقیقی |
| 🏦 سرمایه‌گذاری | نگهداری بلندمدت | تحلیل بنیادی (P/E نسبت به گروه، بازده سود در برابر نرخ بدون ریسک، ارزش نسبی، اندازه، روند و ثبات) |

برای هر سهم نوسان‌گیری، **نقطه ورود، حد ضرر، دو هدف قیمتی، سود خالص پس از کارمزد و تعداد سهم مناسب**
بر اساس سرمایه و ریسک شما محاسبه می‌شود.

## اجرا

نیاز: Python 3.10 یا جدیدتر و اینترنتی که به `tsetmc.com` دسترسی داشته باشد.

- ویندوز: روی `run.bat` دوبار کلیک کنید.
- مک/لینوکس: `./run.sh`

یا به‌صورت دستی:

```sh
pip install -r requirements.txt
streamlit run app.py
```

مرورگر خودکار روی `http://localhost:8501` باز می‌شود.

> اجرای اول برای همه نمادها (حدود ۷۰۰ نماد) چند دقیقه طول می‌کشد. سابقه قیمت‌ها ۶ ساعت در پوشه `.cache`
> ذخیره می‌شود و اجراهای بعدی سریع‌اند. برای سرعت بیشتر می‌توانید در نوار کناری تعداد نمادها را محدود کنید.

اگر TSETMC در دسترس نبود، گزینه «داده نمونه» داشبورد را با داده ساختگی نشان می‌دهد.

## فایل‌ها

- `app.py`: داشبورد (Streamlit)
- `data.py`: دریافت داده از TSETMC (API جدید و قدیم) و تعدیل قیمت
- `indicators.py`: اندیکاتورهای تکنیکال
- `analysis.py`: امتیازدهی نوسان‌گیری و بلندمدت
- `demo.py`: داده ساختگی برای آزمایش
- `tests/`: تست‌ها (`python -m pytest tests`)

## هشدار

این ابزار **مشاوره مالی نیست**. امتیازها قواعد ساده‌اند و آینده را پیش‌بینی نمی‌کنند. EPS از TSETMC
گرفته می‌شود و ممکن است قدیمی باشد؛ پیش از خرید، صورت‌های مالی را در [کدال](https://codal.ir) بررسی کنید.
