# داشبورد تحلیل بورس تهران

برنامه‌ای برای ویندوز که **همه نمادهای بورس و فرابورس** را از TSETMC و کدال می‌خواند و:

| بخش | کاربرد | روش |
|---|---|---|
| ⚡ نوسان‌گیری | معاملات کوتاه‌مدت | تحلیل تکنیکال (EMA، RSI، MACD، بولینگر، ATR، حجم، شکست سقف) + جریان پول حقیقی؛ نقطه ورود، حد ضرر، هدف‌ها و حجم معامله |
| 🏦 سرمایه‌گذاری | نگهداری بلندمدت | تحلیل بنیادی (P/E نسبت به گروه، بازده سود، ارزش نسبی، روند، ثبات) + **رشد فروش ماهانه از کدال** |
| 📄 کدال | هر نماد | آخرین اطلاعیه‌ها (با علامت ⭐ برای موارد مهم مثل مجمع و افزایش سرمایه) و نمودار فروش ماهانه |
| 🔔 تلگرام | هشدار خودکار | ارسال سیگنال‌های قوی نوسان‌گیری، برترین‌های بلندمدت و اطلاعیه‌های مهم کدال به تلگرام |

## نصب (برای شما و هر کس دیگری)

**نیازی به نصب پایتون یا هیچ برنامه دیگری نیست**؛ پایتون و همه کتابخانه‌ها داخل برنامه هستند.

1. به صفحه دانلود بروید: <https://github.com/8p9tvm7hmy-tech/Test/releases/latest>
2. فایل **`BourseDashboard-Setup.exe`** را دانلود و اجرا کنید (نیاز به دسترسی ادمین ندارد).
3. اگر ویندوز پیام «Windows protected your PC» نشان داد، روی **More info** و بعد **Run anyway** بزنید
   (این پیام برای همه برنامه‌هایی است که امضای دیجیتال پولی ندارند).
4. از آیکون **Bourse Dashboard** روی دسکتاپ برنامه را باز کنید. یک پنجره سیاه باز می‌شود و داشبورد
   خودکار در مرورگر نمایش داده می‌شود. تا وقتی از برنامه استفاده می‌کنید آن پنجره را نبندید.

نسخه بدون نصب: `BourseDashboard-Portable.zip` را از همان صفحه بگیرید، از حالت فشرده خارج کنید و
`BourseDashboard.exe` را اجرا کنید. می‌توانید همین فایل‌ها را با فلش یا پیام‌رسان به دیگران بدهید.

> اینترنت باید به `tsetmc.com` و `codal.ir` دسترسی داشته باشد (اینترنت داخل ایران). اگر برای تلگرام
> فیلترشکن دارید، آدرس پروکسی آن را در تب «هشدار تلگرام» وارد کنید.

## راه‌اندازی هشدار تلگرام

1. در تلگرام به **@BotFather** پیام دهید، `/newbot` را بفرستید و توکن ربات را بگیرید.
2. در تب «🔔 هشدار تلگرام» توکن را وارد کنید.
3. ربات خود را در تلگرام باز کنید و **Start** بزنید.
4. «پیدا کردن شناسه چت» و سپس «ارسال پیام آزمایشی» را بزنید.
5. کلید «فعال» را روشن کنید. تا وقتی برنامه باز است، در ساعات بازار هر چند دقیقه بازار بررسی می‌شود
   و هر نماد حداکثر روزی یک بار اعلام می‌شود.

## اجرا از روی کد (برای توسعه‌دهنده‌ها)

```sh
pip install -r requirements.txt
streamlit run app.py          # داشبورد
python alerts.py              # فقط هشدار تلگرام، بدون داشبورد
python -m pytest tests        # تست‌ها
```

ساخت نسخه ویندوز به‌صورت خودکار در GitHub Actions انجام می‌شود (`.github/workflows/build-windows.yml`):
هر تغییر در این پوشه یک نسخه جدید `Setup.exe` می‌سازد و در صفحه Releases منتشر می‌کند. ساخت دستی:
`pyinstaller packaging/BourseDashboard.spec` و سپس کامپایل `packaging/installer.iss` با Inno Setup.

## فایل‌ها

- `app.py`: داشبورد (Streamlit)
- `data.py`: داده TSETMC و تعدیل قیمت · `codal.py`: اطلاعیه‌ها و فروش ماهانه کدال
- `indicators.py`, `analysis.py`: اندیکاتورها و امتیازدهی · `alerts.py`: هشدار تلگرام
- `config.py`: تنظیمات کاربر (در `%APPDATA%\BourseDashboard`) · `launcher.py`: نقطه شروع نسخه نصبی
- `packaging/`: فایل‌های ساخت نصب‌کننده · `demo.py`: داده ساختگی برای آزمایش

## هشدار

این ابزار **مشاوره مالی نیست**. امتیازها قواعد ساده‌اند و آینده را پیش‌بینی نمی‌کنند. خواندن فروش ماهانه
از کدال خودکار است و برای برخی صنایع (بانک، بیمه، سرمایه‌گذاری) ممکن است انجام نشود؛ عدد مهم را با
خود گزارش در کدال تطبیق دهید.
